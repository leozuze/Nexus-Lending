# Nexus Lending

Nexus Lending is a modern, consumer-focused fintech platform designed to democratize credit access through AI-powered technology. By leveraging alternative data modeling, Nexus offers a faster, more transparent, and user-friendly alternative to traditional banking.

## Overview

This project provides the frontend experience for Nexus Lending, with a polished landing page that highlights:

- Faster approval experiences
- Transparent loan terms
- A modern, mobile-friendly interface
- Clear product and trust messaging

## Features

- Responsive landing page design
- Loan product showcase
- Step-by-step explanation of the lending experience
- FAQ and trust-focused sections
- Clear legal and disclosure content

## Tech Stack

- React 19
- Vite
- Tailwind CSS
- Framer Motion
- AOS
- Lucide React

## Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/jayzcreative/Nexus-Lending.git
   ```

2. Install dependencies
   ```bash
   cd Nexus-Lending
   npm install
   ```

3. Start the development server
   ```bash
   npm run dev
   ```

4. Build for production
   ```bash
   npm run build
   ```

## Scripts

- `npm run dev` — start the local development server
- `npm run build` — create a production build
- `npm run lint` — run ESLint checks
- `npm run preview` — preview the production build locally

## Notes

This repository currently focuses on the user-facing frontend experience for Nexus Lending.
